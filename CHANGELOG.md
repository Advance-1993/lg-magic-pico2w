# Changelog

## 0.25 — initial public source snapshot

- BLE MR25GA to USB keyboard/mouse/media on Pico2W; optional Python/Tk companion.
- Persistent single-peer bonds, custom mappings, gain and calibration.
- Configurable inactivity (default90seconds) and host-unavailable radio pause.
- Connection-only LED and safe reconnect cache with full-discovery fallback.
-200ms hold-to-drag with120ms release stabilization; previously350ms in0.24.
- Public export removes operator identities, histories, private host automations
  and build paths. Public images are rebuilt without provisioning data.

This is a cleaned release snapshot, not the private development history.
