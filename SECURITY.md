# Security reporting

No cloud service is operated by this project. Public Issues are appropriate for
ordinary non-sensitive bugs with redacted diagnostics. Do not post pairing keys,
full flash, credentials, device identities or a weaponized vulnerability publicly.

For a security-sensitive issue, use GitHub private vulnerability reporting if the
repository owner has enabled it under Security → Advisories. If unavailable, ask
for a private reporting route without posting sensitive details. No private email
address is embedded in this export. Only the current snapshot is maintained on a
best-effort basis; there is no security support or response-time guarantee.
