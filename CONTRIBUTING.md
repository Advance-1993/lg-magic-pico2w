# Contributing

Read docs/DEVELOPMENT.md and docs/ARCHITECTURE.md. Run Python, native, artifact
and privacy checks before a pull request. Use a small focused change, explain the
observable behavior and distinguish unit/source checks from actual hardware tests.

For another remote report its printed model and sanitized descriptors plus labeled
press/release/scroll samples. Use CDC-only diagnostics first; a familiar name or
pairing success is insufficient. Never experiment with unknown vendor commands,
remote firmware, DFU or microphone writes. Preserve TV recovery and original IR Power.

Keep neutral releases, encrypted identity checks, safe cache fallback and bounded
records. Do not count idle gyro traffic as user activity or log credentials.
Do not include backups, local environments, private paths or hardware identities.
Respect the mixed upstream licenses and retain all original notices. Contributions
must identify copied material and its license. Original additions use the project
additions MIT terms without overriding third-party terms.

Use Issues for reproducible bugs/features. Describe limitations candidly; do not
promise every LG model, exact battery savings or untested security behavior.
