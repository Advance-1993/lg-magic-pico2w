# Instructions for contributors and coding assistants

Read README.md, docs/SETUP.md, docs/ARCHITECTURE.md and docs/VALIDATION.md.
Pico2W/MR25GA are the tested models. Do not assume MR26GA compatibility.
Never add private addresses, flash dumps, bond keys, local history or host TV
configuration. Maintain the export scanner and keep source/header licenses intact.

Do not flash attached hardware without explicit user authorization, model
confirmation, a verified same-board backup and preservation of saved settings.
Do not change remote firmware, send undocumented vendor commands or unregister
without confirming original TV recovery. Routine wake uses ordinary buttons.

Keep key/mouse/media neutral releases, encrypted identity, full-discovery fallback,
single-peer pairing, link-only LED and bounded RAM history. Do not introduce USB
wait/FIFO changes or remote HID suspend experiments without evidence. Default
inactivity90sec; pointer-only120sec;200ms drag and120ms release stabilization.
Tests use fake identities. Explain what was hardware-tested versus source-only.
